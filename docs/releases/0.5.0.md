# Toris Studio 0.5.0

영상·모션 탭이 "주제 → AI 영상" 하나로 시작합니다. 주제 한 줄을 적고 영상 생성을 누르면 기획부터 MP4까지 이 Mac에서 만듭니다.

- **주제 → AI 영상**: 길이(15·30·60초 또는 10~120초), 비율(9:16·16:9·1:1), 스타일, 품질, 나레이션, 자막, 배경음을 고르고 영상 생성을 누릅니다. Agent 탭의 콘텐츠 모델이 스토리보드를 만들고, 모델이 없으면 "템플릿 초안 · AI 미사용"으로 표시한 초안을 씁니다.
- **스토리보드 승인**: 장면별 대본·나레이션·자막·영상 프롬프트·길이를 고친 뒤 이대로 생성을 눌러야 생성이 시작됩니다.
- **로컬 AI 장면 영상**: Wan2.1 T2V 1.3B(가중치 Apache-2.0, MLX 코드 MIT)를 Apple Silicon에서 장면 하나씩 생성합니다. 엔진은 앱에서 설치하며(약 17.6GB) 고정 리비전과 파일 해시를 확인합니다. 메모리 상한은 18GB이고, 24GB에서 검증되지 않은 Wan2.2 5B와 I2V 14B는 비활성으로 표시합니다.
- **나레이션·자막·편집·품질 검사**: Qwen3-TTS 로컬 음성으로 나레이션을 만들고, 음성 길이에 맞춰 SRT 자막을 만든 뒤 FFmpeg로 1080p 출력(자막, 페이드, 코드로 합성한 배경음)을 합니다. 길이·해상도·오디오·검은 화면을 검사하고 실패한 단계만 한 번 다시 실행합니다.
- **중단해도 이어서**: 단계마다 작업 상태를 저장합니다. 일시정지·계속·취소, 장면별 재생성, 나레이션 다시 만들기를 지원하고, 앱을 다시 열면 끝난 장면은 그대로 쓰고 멈춘 곳부터 이어 갑니다.
- **결과**: 완성 영상 재생, 생성 해상도와 출력 해상도, 품질 검사 결과, "영상 상업적 이용 가능"과 "나레이션 화자 권리 조건부" 표시, MP4 저장, 편집기에서 다듬기(기존 편집기 프로젝트로 가져오기), SNS 게시 초안 만들기(게시는 발행 화면에서 승인). 작업 폴더에 provenance.json으로 모델·리비전·라이선스·파일 해시를 남깁니다.
- 기존 직접 편집과 모션 그래픽은 "다른 방식으로 만들기"에서 그대로 엽니다.

확인 범위: Rust·TypeScript 단위·계약 테스트, IPC 고정 응답을 쓴 Chromium 화면 검사, 뮤테이션 검사, 그리고 이 Mac(M5 Pro 24GB)에서 격리된 데이터 폴더로 실제 Wan2.1 추론과 Qwen3-TTS를 돌린 3장면 15초 1080×1920 영상 생성(장면 하나 약 3분, 최대 메모리 약 15.9GB). 패키징한 앱 화면에서 전체 흐름을 끝까지 실행하지는 않았고, 앱 UI에서 엔진을 새로 내려받는 과정도 실제로 실행하지 않았습니다(같은 설치 스크립트를 직접 실행해 확인). Windows·Intel Mac은 AI 장면 생성을 지원하지 않습니다.

생성 결과의 인물·상표·표현이 제3자 권리를 침해하지 않는지는 게시 전에 확인해야 합니다. Mac은 Apple 공증이 적용되지 않았으며 Windows Authenticode는 미설정입니다. Tauri 업데이트 서명은 유지합니다.
