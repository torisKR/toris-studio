# Toris Studio 0.9.0

영상 자동 제작에서 글자·숫자·목록이 움직이는 모션 그래픽 장면을 레퍼런스의 색·글자 크기·리듬대로 만들 수 있고, AI 모델과 운영 상태 조회를 API 키 없이 각 CLI 로그인으로 쓸 수 있습니다. 0.8.0은 공개하지 않고 건너뛴 버전입니다.

- **모션 그래픽 장면 소스**: 영상 자동 제작의 장면 소스에 "실제 사진 쇼츠"·AI 영상에 더해 모션 그래픽이 생겼습니다. 장면은 제목·숫자·목록·인용 배치 중 하나로 기획되고, 배치·글자 크기·색·등장 시각은 코드가 정해 Rust CPU 합성기로 렌더합니다. 영상 엔진·GPU가 필요 없고 같은 입력이면 같은 프레임이 나옵니다. 화면 비율은 9:16·16:9입니다.
- **레퍼런스**: 마음에 드는 모션 그래픽의 "느낌"(팔레트 다섯 색, 글자 크기, 배치, 등장 애니메이션, 장식, 리듬)만 닫힌 값으로 저장합니다. 기본 레퍼런스 6종, 지금 모션 프로젝트에서 저장, 고른 이미지·영상의 대표 색 가져오기(속도와 배치는 재지 않음)로 만듭니다. 문구·로고·이미지·파일 경로는 저장하지 않습니다. 작업을 만들 때 레퍼런스를 스냅샷으로 남기므로 나중에 레퍼런스를 고쳐도 진행 중인 작업은 바뀌지 않습니다. 모션 작업실의 "AI로 만들기"도 같은 레퍼런스를 쓰고, 팔레트 밖 색을 쓴 초안은 받지 않습니다.
- **모델 자동 지정**: Agent 탭의 모델이 비어 있으면 앱이 시작할 때 로그인된 구독 CLI(Claude Code → Codex → Gemini → Cursor → Kiro 순서)를 찾아 에이전트·콘텐츠 작성 모델로 지정하고 "○○로 설정했습니다 · 변경"을 띄웁니다. 로그인 상태 명령만 실행하며 모델을 호출하지 않고 API 키를 건드리지 않습니다. 모델을 직접 비우고 저장하면 다시 채우지 않습니다.
- **CLI 로그인 버튼**: 구독 CLI나 `gh`·`cf`·`wrangler`가 "로그인 필요"면 버튼이 시스템 터미널에서 그 CLI의 공식 로그인 명령만 엽니다. 로그인과 토큰 저장은 각 CLI가 하며 Studio는 토큰을 읽지 않습니다.
- **`gh`·`cf` 운영 조회**: 운영 탭의 GitHub(Actions 최근 실행, 최근 Release)와 Cloudflare(Workers 배포, Pages)를 이 컴퓨터의 공식 CLI 로그인으로 읽습니다. 고정된 읽기 전용 명령만 토큰 환경 변수를 넘기지 않고 실행하며, 오류 원문 대신 미로그인·권한·시간 초과 같은 분류만 보여 줍니다. CLI가 없으면 예전처럼 공개 REST나 `wrangler`를 씁니다. 운영 토큰을 새로 입력하는 칸은 없어졌고, 예전에 저장한 토큰은 삭제만 할 수 있습니다.
- **준비 상태 화면**: 설정에 AI 문구, AI 이미지, 로컬 DB, YouTube·네이버 트렌드, SNS 분석·게시가 각각 무엇이 있어야 동작하는지와 빠진 것을 고치러 가는 버튼을 보여 줍니다.
- **YouTube 계정 토큰 조회**: YouTube Data API 키가 없어도 연결된 YouTube 계정의 읽기 토큰으로 채널 검색·트렌드를 조회합니다. 토큰은 Rust 안에서 고정된 `googleapis.com` 주소에만 씁니다.
- **네이버 글쓰기 보조**: 네이버 블로그는 공식 글쓰기 API가 없어 자동 게시하지 않습니다. 승인한 수동 게시 작업에서 **네이버에서 글쓰기 (제목 복사)**로 제목을 복사하고 내 블로그를 열고, **본문 복사**로 서식 있는 본문을 복사해 네이버 편집기에 붙여 넣습니다. 이 버튼은 아무것도 게시하거나 상태를 바꾸지 않습니다.
- **Toris 연결(로그인만)**: TikTok·Threads·Instagram·Facebook Page·네이버를 개발자 앱 등록 없이 로그인만으로 연결하는 경로가 들어갔습니다. 코드 교환과 시크릿이 필요한 갱신은 Toris OAuth Broker(`https://oauth.toris.kr`)가 하고, 토큰은 OS 키체인에만 저장합니다. 브로커는 배포되어 있지만 지금은 모든 플랫폼이 꺼져 있어, **이 버전에서는 연결 방식에 "내 개발자 앱"만 보입니다.** 브로커가 플랫폼을 켜면 앱 업데이트 없이 선택지가 나타납니다. 브로커는 0.8.0 미만의 앱을 받지 않습니다.
- **Toris 기본 Google 클라이언트**: YouTube·Google Calendar를 시크릿 없이 PKCE로 로그인하는 내장 클라이언트를 지원합니다. **이번 빌드에는 클라이언트 ID를 넣지 않아 꺼져 있고**, 지금처럼 내 Google 클라이언트를 입력해 연결합니다.

알아 둘 점:

- 모션 그래픽 장면은 16:9에 자막 띠가 있고 배치가 패널이면 제목이 충분히 커지지 못하고 줄어듭니다. 차트 배치는 없습니다.
- 이미지·영상에서 가져온 레퍼런스는 색만 잽니다. 속도와 배치는 고른 기준 레퍼런스 값을 씁니다.
- CLI 로그인 버튼의 Windows 동작은 단위 테스트로만 확인했습니다. `wrangler` 출력 형식은 Cloudflare 문서 기준이며 실제로 실행해 보지 않았습니다.

확인 범위: Rust·TypeScript 단위 테스트와 계약 테스트, 뮤테이션 검사, IPC 고정 응답을 쓴 Chromium 화면 검사, 실제 `gh`(2.100.0)·`cf`(1.0.0-beta.14) 출력을 계정 식별자를 지워 저장한 고정 응답 파싱까지입니다. **실제 브로커를 거친 SNS 로그인·토큰 갱신, 실제 Google 계정으로 내장 클라이언트 로그인, 네이버 편집기에 실제로 붙여 넣어 발행, 다른 계정에서의 `gh`·`cf`·`wrangler` 로그인은 이 릴리스 시점에 확인하지 않았습니다.**

Mac은 Apple 공증이 적용되지 않았으며 Windows Authenticode는 미설정입니다. Tauri 업데이트 서명은 유지합니다. 자세한 내용은 [모션 그래픽](../MOTION_GRAPHICS.md), [영상 자동 제작](../VIDEO_PRODUCTION.md), [OAuth 연결](../OAUTH.md), [운영 허브](../OPS_HUB.md), [AI 모델 연결](../AI_PROVIDERS.md)을 참고하세요.
