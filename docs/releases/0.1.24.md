# Toris Studio 0.1.24

기존 SNS 기능의 부분 대상 승인·재승인 검증을 강화한 안정화 패치입니다. 새 SNS 채널이나 게시 종류를 추가하지 않습니다.

## 변경 사항

- 브라우저 IPC fixture가 새 초안의 id·revision·작업을 이전 초안과 분리합니다.
- 선택한 대상만 job으로 만들고, 다음 부분 승인에서도 이미 완료한 대상의 결과와 ID를 보존합니다.
- 대상 선택을 바꾸면 검사·동의를 다시 요구하고, 미선택 채널은 검사·승인·작업 생성에서 제외되는 경로를 회귀 검증합니다.
- YouTube 일부 승인 후 TikTok 받은 편지함만 별도 승인하는 화면 검증을 추가했습니다. 초안 전송과 실제 게시 완료를 구분합니다.
- 검증 하네스 개선이며, 확인되지 않은 실제 SNS 게시 버그를 수정했다고 주장하지 않습니다. 기존 앱의 승인형 실행 구조는 유지합니다.

## 사용 조건과 제외 범위

TikTok 영상 Direct/받은 편지함, Page·Threads 텍스트, 네이버 수동 인계의 기존 범위를 유지합니다. 미심사 TikTok Direct는 비공개 계정의 SELF_ONLY로 제한되며 공개 Direct는 심사·권한·실제 API 허용이 필요합니다. TikTok 초안은 사용자가 최종 게시하고 네이버는 수동 인계입니다.

X, 여러 콘텐츠 CSV/JSON 등록, 반복 예약, 이미지·캐러셀 자동 게시는 추가하지 않았습니다. 앱 종료·PC 절전/전원 종료 중에는 로컬 예약을 실행하지 않습니다.
