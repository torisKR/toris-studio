# Toris Studio 0.3.0

- **SNS 관리 통합**: 내 채널, YouTube 공개 참고 조회, 여러 OAuth 계정, 연결·권한 진단을 한곳에서 관리합니다.
- **채널 성과 분석**: YouTube·Instagram·Facebook Page·Threads·TikTok의 제공 범위를 구분해 표시합니다. 실제 권한·표본·집계 지연에 따라 일부 지표는 제공되지 않을 수 있습니다.
- **보고서 가져오기**: CSV·Excel·표를 매핑하고 원본 수치·정의·기간·시간대를 검토한 뒤 저장합니다. 계정을 다시 연결해도 보고서 이력과 수정 관계를 유지합니다.
- **Remote Desktop Commander**: 문구·이미지·영상·모션 제작 연결을 RDC로 통일하고 코딩 화면·Codexify 실행기·브리지·번들을 제거했습니다. 실제 요청 조회와 초안 수신을 구분하고 적용·게시 전 검토를 유지합니다.
- **게시 안전성**: 승인 작업을 실제 계정에 고정하고 연결 해제 시 해당 예약과 API 캐시를 정리합니다. DB 장애·재연결·정리 작업 경합도 처리합니다.
- X와 네이버 블로그·클립은 수동 보고서와 사용자 확인 게시 흐름을 사용합니다. 유료 X API는 추가하지 않았습니다.
- 기존 로컬 DB·계정 설정·프로젝트·음성·영상 출력과 Playwright 브라우저를 보존합니다.

서명된 업데이트는 앱의 설정에서 확인할 수 있습니다. macOS Apple Silicon·Intel과 Windows x64 설치 파일을 제공합니다. Mac은 ad-hoc 서명이며 Apple 공증이 적용되지 않았습니다. Windows Authenticode는 미설정이며 Tauri 업데이트 서명과 구분합니다.
