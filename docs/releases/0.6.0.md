# Toris Studio 0.6.0

영상·모션 탭의 기본 장면 소스가 "실제 사진 + 모션 그래픽"으로 바뀌었습니다. 주제를 적으면 장면마다 상업적 이용 가능한 사진을 찾아 쇼츠 구성(위 고정 제목, 강조 자막, 숫자 카드, 사진 움직임, 출처 표시)으로 영상을 만듭니다.

- **저작권 걱정 없는 사진 자동 검색**: 기획 모델이 장면마다 영어 검색어를 쓰고, 앱이 Openverse(Flickr·StockSnap·Wikimedia Commons 등)와 Wikimedia Commons에서 CC0·퍼블릭 도메인·CC BY 사진만 찾습니다. CC BY-SA·비영리·변경 금지 사진, 초상권·상표 제한이 적힌 사진, 방송사·통신사·뉴스 화면은 후보에서 뺍니다. API 키 없이 동작합니다.
- **장면별 사진 고르기**: 스토리보드 확인 화면에서 장면마다 사진 후보 3장과 라이선스를 보고 고르거나, 검색어를 바꿔 다시 찾습니다. 상단 두 줄 제목, 노란 강조 단어, 사진 움직임(확대·축소·좌우·위로), 숫자 카드도 여기서 고칩니다.
- **쇼츠 모션 그래픽**: 1080×1920 기준 위에 흰색·노란색 두 줄 제목을 고정하고, 가운데 사진은 천천히 움직이며, 자막은 검은 상자에 강조 단어를 노랗게 넣어 짧게 튀어나옵니다. 숫자가 핵심인 장면은 큰 숫자 카드가 올라오고, 아래에는 사진 출처와 진행 막대가 나옵니다. 3~4초 컷으로 빠르게 넘깁니다.
- **출처 자동 기록**: 쓴 사진의 작성자·출처·라이선스·원본 주소가 provenance.json, 결과 화면, SNS 게시 초안 설명의 "사진 출처" 목록에 들어갑니다. 라이선스 기록이 다시 검사를 통과하지 못하면 상업적 이용 표시를 끕니다.
- **멈추지 않는 진행**: 사진을 내려받지 못하면 다음 후보로, 후보가 없으면 자막을 크게 넣은 그래픽 장면으로 바꾸고 작업 기록에 남깁니다. 완성 뒤에는 장면마다 "다른 사진으로"를 누를 수 있습니다.
- 기존 AI 장면 생성(Wan2.1)은 "AI 장면 생성"을 고르면 그대로 쓰고, 쇼츠 카드 구성도 함께 쓸 수 있습니다. 0.5.x에서 만든 작업은 예전 방식(AI 전체 화면)으로 열립니다.

확인 범위: Rust·TypeScript 단위 테스트와 뮤테이션 검사(라이선스·방송사·호스트·썸네일 크기 판정 포함), IPC 고정 응답을 쓴 Chromium 화면 검사, 그리고 이 Mac에서 격리된 데이터 폴더로 실제 Openverse·Commons 검색과 내려받기, 실제 Qwen3-TTS, 실제 FFmpeg 합성을 거친 15초 1080×1920 쇼츠 2편 생성(품질 검사 9/9 통과). 앱 UI에서 실제 모델 기획부터 사진 쇼츠 완성까지의 흐름은 패키징 앱으로 따로 확인합니다.

라이선스가 허용해도 사진에 찍힌 인물·상표·건축물의 권리와 사실 관계는 게시 전에 확인해야 합니다. Openverse는 키 없이 분당 20회·하루 200회까지 검색할 수 있어 긴 영상을 여러 편 연달아 만들면 잠시 기다려야 할 수 있습니다. Mac은 Apple 공증이 적용되지 않았으며 Windows Authenticode는 미설정입니다. Tauri 업데이트 서명은 유지합니다.
