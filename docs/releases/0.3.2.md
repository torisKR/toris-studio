# Toris Studio 0.3.2

- macOS에서 SNS 연결 정보를 조회할 때 저장소 키 검증 오류가 키체인 권한 경고로 표시되던 문제를 수정했습니다. 새 연결 저장소가 사용하는 정확한 키만 허용하고, 잘못된 키는 계속 거부합니다.
- 기존 항목을 유지하면서 새 연결·복구 기록을 보관할 수 있도록 저장 개수 한도를 조정했습니다. 개별 항목 64 KiB와 전체 1,500,000바이트 제한은 유지합니다.
- 실제 SNS 연결 저장소와 네이티브 자격 증명 저장소 사이의 계약을 회귀 검사합니다. 실제 OS 키체인·사용자 계정·DB를 읽거나 변경하지 않는 격리 검사를 사용합니다.
- 0.3.1의 설정 복원·빈 본문 수정과 SNS 통합 관리·Remote Desktop Commander 연결을 포함합니다.

기존 DB·계정 설정·프로젝트·제작 요청을 유지합니다. macOS ad-hoc 빌드를 교체한 뒤에는 시스템이 키체인 접근 승인을 다시 요청할 수 있습니다. Mac은 Apple 공증이 적용되지 않았으며 Windows Authenticode는 미설정입니다. Tauri 업데이트 서명은 유지합니다.
