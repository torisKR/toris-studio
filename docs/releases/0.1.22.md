# Toris Studio 0.1.22

영상 스튜디오에서 템플릿을 선택하고, 내 주제의 장면 구성을 먼저 확인한 뒤 편집을 시작할 수 있습니다.

- 원본 스타일의 영상 템플릿 10종과 검색·카테고리 필터
- 재실행 뒤에도 유지되는 즐겨찾기와 최근 사용
- 미리보기 옆에서 주제·카테고리·형식·언어·장면 수·길이 변경
- 장면 타임라인, 제목·본문·내레이션 초안, 모션 재생
- 저장 전 확인과 원본을 보존하는 프로젝트 복제
- OS 저장 창을 사용하는 스토리보드 Markdown·프로젝트 JSON 내보내기
- 선택한 구성을 실제 ChatGPT 대화 요청과 Rust MP4 출력에 연결
- 업데이트 진행 표시, 작업 중 설치 보호, 네이티브 영상 미리보기 창, 화면 이동 단축키
- 타이머·이벤트·영상 디코더·3D 리소스 정리와 데스크톱 IPC 권한 제한
- OAuth 프록시의 고정 전달 origin과 의존성 보안 수정

템플릿 미리보기는 편집 가능한 구성 초안입니다. 이미지·음성 또는 ChatGPT 응답이 실제 생성되었다고 표시하지 않으며, ChatGPT 요청은 사용자가 연결한 실제 대화를 이용합니다.

Mac Apple Silicon·Mac Intel·Windows x64는 기존 빌드 파이프라인을 사용합니다. 앱의 업데이트 확인은 GitHub Release에서 업데이트 서명을 검증하고 설치하며, 같은 배포 파일 묶음은 GitHub Packages에도 보관합니다. OAuth Worker 소스 수정은 이번 데스크톱 배포와 별도로 공개 배포 반영 여부를 확인해야 합니다.
