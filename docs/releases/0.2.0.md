# Toris Studio 0.2.0 검증 기록

상태: 구현 및 배포 전 검증 중. 공개 릴리스 아님. 설치된 앱은 교체하지 않음.

- 영상 제작에 모션 그래픽 모드, 버전 1 장면·요소 계약, 자료·표·이미지 입력, 직접 편집과 실행 취소를 추가함.
- 요청 해시·선택 ID·초안 검토·수동 편집 충돌·멱등 수신·취소·보관을 구현함. 원본 수치 변경은 명시적 허용과 전후 값 검토를 요구함.
- Rust 공통 합성기로 정지/재생 미리보기와 1080p 24fps H.264/AAC 출력. FFmpeg 9.0.2 소스 빌드, Noto CJK와 대응 소스·라이선스 동봉.
- 이전 feat/playwright-browser의 번들 Playwright 브라우저 전환 커밋도 포함함.
- 로컬 Mac ARM에서 빈 PATH의 설치 검사 통과: Korean text, chart, image, portrait MP4, even-dimension landscape preview. 실제 MP4 시작·중간·끝과 공통 합성기 프레임의 평균 RGB 차이 <3/255.
- 실제 저장된 Codexify 연결 검사: reachable=false, ownerReady=false. 실제 ChatGPT 왕복은 미검증. UI에서 사용하는 응답은 fixture임.
- 세 플랫폼 설치 파일 재추출, 공개 해시·서명·업데이트 피드·GHCR 검증은 아직 미완료.

Mac Developer ID/공증·Windows Authenticode 상태는 최종 CI 설정과 산출물로 확인해야 함. 로컬 개발 미디어 구성요소는 ad-hoc 서명, JIT 권한 없음.

로컬 검증 (2026-10-21):
- JS/TS 전체: 218 통과, 외부 DB 테스트 1개 건너뜀.
- Rust no-default-features 전체: 321 통과, 외부 환경/미디어 명시 실행 테스트 14개 제외. 별도로 미디어 fixture 1개 및 기존 프리셋/음성/미디어 6개를 실제 번들 도구로 실행해 통과.
- 릴리스·브라우저 런타임 계약 42개, OAuth 콜백 13개 통과. 타입 검사 및 Next/Vite 빌드 통과.
- 모션 UI: 실제 Rust 합성기/초안 저장소 + fixture ChatGPT 응답으로 6개 사용자 흐름 통과. 실제 ChatGPT 왕복과 구분함.
- 기존 브라우저 설정/OAuth 시스템 브라우저 인계 UI 회귀 통과. Git 기록과 배포 대상 파일 비밀정보 검사 통과.
