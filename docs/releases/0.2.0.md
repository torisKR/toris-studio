상태: main·v0.2.0 및 공개 배포 완료 (2026-10-21 KST). 설치된 앱은 교체하지 않음.

소스: `d2bd086b0dcb0fac84a2d828da69632ab5a00acf` (`v0.2.0`). PR은 `ebb2a73371623f3b32a2fb1cbbec326290c31d84`로 병합됨. 검증된 PR 머리 `c36c568b84f66d8ddbaee52ad05126b16e7768d6`과 앱·렌더러·번들 소스가 동일하며, 릴리스 전용 검사에서 발견한 OS별 경로 테스트 기대값과 느린 Intel QA 대기·실패 기록 수정만 추가됨. [PR #10](https://github.com/torisKR/toris-studio/pull/10).

## 구현

- 모션 그래픽 모드: 한국어·세로·5장면·45초 기본값, 5가지 시작 구성, 설명문·CSV·이미지 입력, 장면/요소 편집·실행 취소·복원·가로 전환.
- 요청 해시·선택 ID·변경 전후 검토·수동 편집 충돌·멱등 수신·취소·보관. 원본 수치 변경은 명시적 허용과 기존/새 수치 검토를 요구함.
- Rust 공통 합성기로 정지/재생 미리보기와 1080p 24fps H.264/AAC 출력. FFmpeg 9.0.2/libx264/zlib 1.3.2와 Noto CJK, 대응 소스·해시·라이선스 동봉.
- Remote Desktop Commander 전달문을 기본 연결로 제공하고 기존 Codexify도 선택 가능. 별도 모델 API 키 없음. 이전 Playwright 브라우저 전환도 포함.

- 5장면·45초 합성 프로젝트를 실제 1080×1920/24fps로 출력: 영상 1,080프레임, 컨테이너 45.021333초. 시작/중간/끝은 각각 1/3/5번째 장면. 같은 시각 공통 합성기 프레임과 디코딩한 MP4의 평균 RGB 차이 1.672/1.128/1.426 (<3/255). 한글·수치·이미지를 직접 확인함. 임시 로컬 진단이며 CI fixture와 구분함.
- 패키징·릴리스 계약 44개, OAuth 콜백 13개 통과. 웹·데스크톱 타입 검사/빌드, 기존 브라우저/OAuth UI 회귀, 비밀정보 검사 통과.
- 모션 UI는 실제 Rust 합성기/초안 저장소와 명시적인 ChatGPT fixture로 6개 사용자 흐름 검증. 실제 연결 결과를 대신하지 않음.
- 독립 읽기 전용 검토의 차단 문제를 수정했으며, Remote Desktop Commander 및 최종 Windows 도구체인 변경분의 추가 검토에서도 새 차단 문제가 발견되지 않음.

## 실제 ChatGPT 연결

사용자 지정 Remote Desktop Commander 경로로 이 ChatGPT 대화 → 원격 도구 → native stdio MCP 요청 읽기·초안 반환 왕복 통과. 격리 합성 프로젝트에서 Q3 17→18, 장면 9→12초 초안을 실제 대화가 작성·반환했음. 요청 생성은 production request_at을 호출하는 QA 어댑터이며, 검토 계산에서 원본 스냅샷·다른 요소·Q1/Q2 보존을 확인함. 프로젝트 저장·적용 및 기존 사용자 데이터 접근은 실행하지 않았음. 자동 UI 응답 fixture와 별도 증거임.

## 준비 단계에서 해결한 검사 문제

첫 릴리스 준비 실행 39474965005는 Windows에서 Mac 경로 테스트의 `/` 고정 기대값으로 실패했으며 공개 게시 전에 중단됨. OS 경로 규칙에 맞춘 테스트 수정 후 계약 44개를 다시 통과했고, 공개 Release/배포 파일이 없는 것을 확인한 뒤 준비 태그를 새 커밋에 동기화해 재실행함. 제품 코드는 변경하지 않음.

두 번째 준비 실행 39476173258은 ARM·Windows 전체 성공, Intel은 설치 파일·서명·런타임 검사 후 UI 검토 화면의 30초 제한으로 실패해 공개 게시가 실행되지 않았음. [Intel 진단 39483715375](https://github.com/torisKR/toris-studio/actions/runs/39483715375)에서 전후 합성 29.075초+13.605초(약42.7초), 정상 종료·오류 없음 및 UI6개 흐름 통과를 확인함. QA는 IPC마다 새 디버그 프로세스로 CJK 폰트/리소스 캐시를 초기화하지만 앱은 프로세스 캐시를 사용함. 프레임 조건60초·두 프레임 검토120초로 예산을 나누고 PID·시간·stderr·실패 화면/보고서와 CI 아티팩트를 보존하도록 d2bd086에서 보완. 모든 검증 조건은 유지했고 로컬 UI6개·계약44개 및 독립 검토 통과. 공개 파일이 없는 준비 태그만 기록된 이전 개체에 대한 force-with-lease로 동기화했음.

Mac은 ad-hoc 서명이며 Developer ID·Apple 공증은 설정돼 있지 않음. Windows Authenticode도 설정돼 있지 않음. 세 플랫폼 Tauri 업데이트 서명은 별도 암호 검증을 통과했음. 기존 계정·설정·프로젝트와 원본 작업 폴더의 campaigns/, pocket-circuit/을 보존했으며 설치본 교체는 수행하지 않음.
