# Toris Studio 0.1.23

SNS 일괄 게시에서 영상·텍스트·블로그 원고를 구분하고, TikTok 영상 예약·초안 전송과 네이버 수동 인계를 기존 승인형 큐에서 관리합니다.

## 변경 사항

- 기존 YouTube·Instagram Reels·Facebook Page·Threads·TikTok 영상 게시 경로에 콘텐츠 종류 선택을 연결했습니다.
- Facebook Page·Threads 텍스트 게시와 승인한 예약을 지원합니다.
- 한 콘텐츠의 자동 게시 채널에 KST 시작 시각과 간격을 초안으로 적용할 수 있습니다. TikTok Direct는 포함하고 받은 편지함 초안과 네이버 수동 인계는 제외합니다.
- TikTok은 공개 범위를 자동 선택하지 않습니다. 최신 계정 설정·명시적 음악/전송 동의·별도 최종 승인을 유지하고, Direct와 받은 편지함 초안의 결과를 구분합니다.
- TikTok 비공개 Direct 예약과 받은 편지함 제외, 업로드 전 원격 ID 저장 실패 시 전송 차단을 회귀 검증에 포함했습니다.
- 네이버 블로그 제목·본문·태그와 최대 20개 이미지를 로컬 인계 폴더로 내보냅니다.
- 내보내기만으로 게시 완료가 되지 않습니다. 실제 게시 후 해당 블로그의 URL과 사용자 확인으로 기록하며 API 검증과 구분합니다.
- 초안 변경 시 재승인을 요구하고, 불명확한 전송 결과를 새 게시 요청으로 반복하지 않습니다.
- 임시 PostgreSQL·브라우저 IPC fixture 검증을 main과 서명 배포의 필수 gate로 연결했습니다.

## TikTok 사용 조건

Direct Post는 `video.publish`, 받은 편지함 초안은 `video.upload` 승인과 사용자 권한이 필요합니다. 미심사 앱의 Direct는 비공개 계정의 SELF_ONLY로 제한되며, 공개 Direct(예약 포함)는 앱 심사와 실제 API 허용이 필요합니다. 내부·개인용 도구의 공개 심사는 보장하지 않습니다. 개발자 콘솔 승인 선언은 실제 게시 성공의 증거가 아닙니다.

초안 전송은 영상만 전달합니다. TikTok 알림에서 사용자가 문구·설정을 확인하고 최종 게시해야 하며, ‘초안 전송 완료’는 ‘게시 완료’가 아닙니다. 이 릴리스의 TikTok 경로는 영상 전용이며 텍스트·사진 게시는 지원하지 않습니다.

## 아직 포함하지 않는 기능

X 연결·자동 게시, 여러 콘텐츠 JSON/CSV 배치 등록, 반복 예약, 이미지·캐러셀 자동 게시는 후속 범위입니다. 네이버는 완전 무인 게시가 아닙니다. 앱 완전 종료·PC 절전/전원 종료 중에는 로컬 예약이 실행되지 않습니다.
