# Toris Studio 0.4.2

영상 제작에 AI 모션 생성과 로컬 내레이션을 넣었고, AI 모델은 고르기만 하면 연결 상태를 바로 확인합니다.

- **AI 모델 연결 (Agent › 모델 설정)**: 공급자(Codex·Claude Code·Kiro·Cursor·Gemini CLI, OpenAI·Anthropic·Gemini·OpenRouter API, Ollama)와 모델을 모두 선택 목록으로 고릅니다. 공급자를 고르면 로그인·API 키·실행 상태를 확인해 연결됨·로그인 필요·키 필요·꺼짐을 보여 주고, 그 계정에서 쓸 수 있는 모델 목록(Kiro·Cursor·Codex CLI, API 키 공급자)을 채웁니다. 다시 확인 버튼으로 언제든 재확인합니다. 확인할 때 프롬프트는 보내지 않습니다.
- **AI로 모션 만들기 (영상·모션 › 모션 그래픽)**: 원하는 모션을 문장으로 적으면 콘텐츠 작성 모델이 장면·요소·애니메이션 초안을 만들고, 검토한 뒤 적용합니다. AI 출력은 정해진 요소 종류와 범위 안의 숫자만 받으며, 형식이 틀리면 한 번 다시 요청합니다. Studio MCP로 외부 AI 도구와 작업하는 방식은 접힌 옵션으로 남겼습니다.
- **로컬 내레이션 (MLX-Narration 통합)**: 설정 › 로컬 음성에서 Qwen3-TTS(MLX) 엔진을 설치·켜기·끄기 합니다. MLX-Narration을 이미 설치했다면 그 Python 환경과 Hugging Face 모델 캐시를 읽기 전용으로 그대로 씁니다. 앱이 켠 음성 서버는 앱을 끄면 함께 꺼집니다.
- **내레이션 음성 설정**: 영상마다 화자 9명, 톤 8가지(자연스럽게·차분한 다큐·IT 뉴스·활기찬 쇼츠 등), 강조 세기, 품질(안정·표준·표현력), 문장 사이 쉼을 고릅니다. 내레이션 줄 앞에 [차분한 다큐] [Ryan] [쉼:600]을 붙여 줄마다 바꾸고 **단어**로 강조합니다. 태그와 ** 표시는 자막에 나오지 않습니다.
- **상업적 이용 표시**: 로컬 음성 옆에 "상업적 이용 가능 · 모델 Apache-2.0"을 표시하고, 근거(모델 Apache-2.0, 런타임 MIT/BSD)와 주의할 점(내장 화자의 원 화자 권리는 Qwen이 밝히지 않음, 실제 사람 목소리 복제는 본인 동의 필요)을 함께 보여 줍니다.

확인 범위: 단위·계약 테스트(Rust·TypeScript·Python), IPC 고정 응답을 쓴 Chromium 화면 검사, 뮤테이션 검사, 로컬에서 패키징한 macOS 앱으로 Kiro·Cursor·Codex·Claude Code의 실제 로그인 상태와 모델 목록 확인, 앱에서 로컬 음성 서버를 켜 실제 WAV 5개 생성. 이 Mac에서는 엔진이 이미 설치되어 있어 새로 설치하는 과정은 실행하지 않았고, Windows·Intel Mac에서는 로컬 음성 엔진을 지원하지 않습니다.

Mac은 Apple 공증이 적용되지 않았으며 Windows Authenticode는 미설정입니다. Tauri 업데이트 서명은 유지합니다.
