# Toris Studio 0.4.0

1인 개발자·사업자가 SNS·앱·웹·서비스·일정을 한 앱에서 운영하도록 **운영** 메뉴와 Agent를 추가했습니다.

- **운영 → 일정·작업**: 다가오는 8일 일정, 열린 작업, 마감 지난 작업을 봅니다. SNS 게시 예약은 자동으로 일정에 들어옵니다. Google Calendar와 양방향 동기화하며 범위는 Studio가 만든 캘린더 하나(`calendar.app.created`)입니다. 기존 캘린더는 읽지 않습니다.
- **운영 → 운영 상태**: 제품마다 GitHub CI·릴리스, Cloudflare Workers/Pages 배포, HTTPS 헬스체크, Google Play 트랙 상태를 읽기 전용으로 모읍니다. CI 통과·배포됨·정상 응답·심사 중·공개를 각각 따로 표시하고, 실패 항목은 작업으로 넘깁니다. 토큰은 OS 키체인에만 저장합니다.
- **제작 → Agent**: 프로젝트 코드 작업(Supervisor·Frontend·Backend·QA, LangGraph)과 운영 워크플로 두 가지(주간 콘텐츠 초안, 운영 점검)를 실행합니다. 파일 변경·명령 실행·초안 저장은 항목마다 승인합니다.
- 문구·영상 초안·SNS 문구·이미지 생성은 Agent의 모델 설정(구독 CLI·API 키·Ollama)을 사용합니다. 모델이 없으면 영상과 주간 콘텐츠는 `[템플릿]` 초안으로 만들며 AI 결과로 표시하지 않습니다. Studio MCP로 외부 도구가 보낸 초안 수신은 그대로 유지합니다.
- 모션 프리셋 6종(lower-third, count-up, bar-chart, progress-steps, quote-card, logo-reveal)과 장면 전환(cut·fade·dip), 자막 cue를 추가했습니다. 모두 Rust·FFmpeg로 렌더합니다.
- 번들 cloudflared를 2026.10.4로 올렸습니다(Go 1.27.3, macOS 13 이상에서 미디어 터널 사용).
- 새 DB 마이그레이션 `012_planner`, `013_ops_status`는 기존 데이터를 유지하고 테이블만 추가합니다.

확인 범위: 단위·계약 테스트, 격리 PostgreSQL 마이그레이션, IPC 고정 응답을 쓴 Chromium 화면 검사, 뮤테이션 검사. 실제 Google 로그인과 동기화, 실제 모델 생성, GitHub·Cloudflare·Play 토큰 호출은 출시 전 검사에 포함되지 않았습니다. Play 서비스 계정에는 Play Console에서 앱 정보 보기 권한만 주세요.

Mac은 Apple 공증이 적용되지 않았으며 Windows Authenticode는 미설정입니다. Tauri 업데이트 서명은 유지합니다.
