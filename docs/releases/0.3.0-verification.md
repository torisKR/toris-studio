# 0.3.0 배포·설치 검증

이 문서는 개발 검증과 실제 공개 파일·설치본 검증을 구분합니다. 파일 공개·서명 검증과 설치 교체는 통과했으나 실제 설치 앱의 시작 화면이 비어 있는 문제를 확인해 **0.3.0을 prerelease로 전환하고 안정 최신 배포에서 제외했습니다.** 기존 설정 화면 복원 시 삭제된 코딩 설정 배열을 참조하던 것이 원인이며 0.3.1에서 수정합니다.

## 대상

- 버전: `0.3.0`
- 앱 소스: `bbe298548970749fb5a57222878a5c1f05b3cfea`
- [배포 실행 39600915672](https://github.com/torisKR/toris-studio/actions/runs/39600915672)
- [다운로드 안내](https://toriskr.github.io/toris-studio/)
- 사용자 데이터와 원래 작업 디렉터리의 미추적 폴더는 배포 대상에서 제외합니다.

## 개발·배포 전 검사

- JavaScript: 195개 중 194 통과, 1 명시적 건너뜀, 실패 없음.
- Mac ARM Rust 전체: 343 통과, 20 명시적 무시. Windows: 336 통과, 20 명시적 무시. 플랫폼별 검사 수 차이가 있으며 두 플랫폼 모두 실패가 없습니다.
- TypeScript, Vite, Next 프로덕션 빌드 통과.
- MCP 의존성을 수정 버전으로 갱신했고 잠금 파일 기준 의존성 보안 검사에서 취약점 0건을 확인했습니다. 릴리스에도 같은 검사를 필수 적용했습니다.
- 격리 PostgreSQL에서 게시 큐 2개·분석 7개 통합 검사 통과.
- 게시 UI 19개·SNS UI 12개 검사 그룹 통과. OAuth 콜백 13개·릴리스 계약 3개 검사 통과.
- 실제 RDC 경유 네이티브 제작 요청 조회·초안 수신 왕복을 개발 바이너리와 격리 저장소로 확인했습니다.
- 실제 동봉 도구로 한글·이미지·차트 MP4를 만들고 시작·중간·끝 프레임을 네이티브 미리보기와 비교했습니다.
- Mac ARM·Intel·Windows CI에서 네이티브 모션 편집기와 설치 파일 재추출 검사가 모두 통과했습니다. 재추출 앱은 빈 `PATH`로 실행하며 H.264/AAC·24fps·1080×1920 출력과 가로 미리보기, 동일 Rust 합성기를 확인합니다. smoke는 사용자 데이터를 읽지 않습니다.
- ARM·Windows의 추가 패키징·런타임 45개, AI JavaScript 14개, 실제 stdio MCP의 14개 도구 계약과 headed browser 검사가 통과했습니다. 모션 UI 초안은 fixture이며 실제 ChatGPT 실행과 구분합니다.
- 실제 SNS 제공자 로그인·성과 API 조회와 fixture 검증은 별개입니다. 제공자 계정의 실제 로그인·성과 조회 완료를 주장하지 않습니다.

## 배포 중 수정한 문제

- 첫 실행은 MCP SDK 보안 권고 검사에서 중단했습니다. 수정 버전과 필수 릴리스 보안 검사를 반영해 다시 실행했습니다.
- 다음 실행은 CI에 존재하지 않는 사용자 자격 증명 경로를 음성 검사에 사용하던 fixture에서 중단했습니다. 검사가 소유하는 임시 디렉터리에 무해한 sentinel을 만들고 실제 403 응답과 내용 비노출을 검사하도록 수정했습니다. 실제 사용자 자격 증명은 읽지 않으며 Vite 접근 정책도 완화하지 않았습니다.
- 두 실패 실행 모두 공개 게시 단계에 도달하지 않았습니다. 기존 공개 0.2.0 파일은 보존했습니다.

## 설치본 교체 검증

기존 설치 앱과 DB 백업을 만들었고 DB 백업은 PostgreSQL 도구로 구조를 확인했습니다. 실제 사용자 데이터와 백업 파일은 저장소나 릴리스에 포함하지 않습니다.

- 기존 0.2.0 앱이 0.3.0을 조회했고 앱 자체의 다운로드·서명 검사·교체·재시작으로 설치했습니다.
- `/Applications/Toris Studio.app`의 버전 `0.3.0`, strict 코드 서명, 공개 ARM 실행 파일과 SHA256 일치, Codexify 이름을 포함한 번들 파일 0개를 확인했습니다.
- 설치 바이너리의 `--self-check`에서 실제 로컬 PostgreSQL 연결과 기존 채널·콘텐츠를 확인했습니다. 에셋 snapshot으로 기존 대기 요청 2개가 유지되고 영상 프로젝트 7개도 보존됐음을 확인했습니다. 제목·본문·프롬프트·계정 값은 검증 문서에 포함하지 않습니다.
- 실제 RDC에서 설치된 바이너리의 stdio MCP `initialize` 버전 0.3.0·14개 도구·`studio_connection_check` 성공을 확인했습니다. 이 호출은 연결 기록만 갱신하며 생성·파일 수신·게시 완료를 의미하지 않습니다. 검증용 MCP 프로세스만 종료했습니다.
- **미통과:** 실제 GUI는 로딩 문구 이후 빈 화면으로 남았습니다. 프로세스는 이벤트 루프에서 실행 중이며 DB·키체인 대기는 아니었습니다. 별도 진단 앱에서 설정 화면의 `opencodexAllowedModels.join` 참조 오류를 확인했습니다. 이전 브라우저 fixture에 삭제된 설정 필드가 남아 있어 검사가 문제를 가렸습니다. 0.3.1은 실제 Rust 공개 설정 DTO를 사용하고 설정 화면이 완전히 열린 뒤에만 네이티브 시작 검사를 통과시킵니다. 기존 코드의 실패와 수정본의 성공을 실제 Tauri/WebKit에서 각각 확인했습니다.

## 서명 상태

Tauri 업데이트 서명 키는 기존 공개 키를 유지합니다. Mac은 ad-hoc 코드 서명이며 Apple 공증이 적용되지 않았습니다. Windows Authenticode는 미설정입니다. 이 상태는 Tauri 업데이트 파일의 서명·버전 검증과 구분합니다.
