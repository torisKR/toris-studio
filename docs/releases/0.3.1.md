# Toris Studio 0.3.1

- 기존 앱이 설정 화면을 복원할 때 내용이 비어 있던 문제를 수정했습니다. 설정 초기화·저장 코드에 남아 있던 코딩·모델 실행기 항목을 제거하고 실제 Rust 설정 응답과 일치시켰습니다.
- 시작 오류가 발생하면 저장된 데이터를 유지하면서 한국어 복구 안내와 다시 불러오기 버튼을 표시합니다.
- 날짜 표시 형식에 의존하지 않고 한국 시간대의 분석 기간을 계산합니다.
- 재추출 설치 파일로 실제 Tauri 시작 화면과 설정 화면을 검사합니다. 사용자 DB·키체인·프로젝트를 읽지 않는 격리 검사이며, 기존 문제가 실패하는 것과 수정본이 통과하는 것을 구분해 검증합니다.
- SNS 통합 관리·보고서·Remote Desktop Commander 제작 연결은 0.3.0의 변경을 포함합니다. 시작 화면 문제로 0.3.0은 prerelease 상태로 보존합니다.

기존 DB·설정·채널·프로젝트·제작 요청을 유지합니다. Mac은 ad-hoc 서명이며 Apple 공증이 적용되지 않았습니다. Windows Authenticode는 미설정이며 Tauri 업데이트 서명은 유지합니다.
