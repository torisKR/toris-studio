# Toris Studio 0.7.0

Agent 탭의 Reason Network에서 디자인·기획·개발·음향·배포를 여러 AI 에이전트에게 차례로 맡길 수 있고, Android 리모컨으로 Mac의 작업을 시작하고 확인할 수 있습니다. 공개되지 않았던 0.6.0의 사진 쇼츠 제작([0.6.0 노트](0.6.0.md))도 이 버전에 함께 들어 있습니다.

- **Reason Network 연결**: 이 컴퓨터에 설치된 Reason Network에 Studio가 전용 세션으로 접속해 연결된 에이전트 목록을 보고, 한 에이전트를 골라 메시지를 주고받습니다. 설치·로그인·네트워크 가입은 Studio가 대신 하지 않으며 Reason 토큰을 Studio에 입력하지 않습니다.
- **단계별 작업 맡기기**: 브리프를 쓰고 디자인 → 기획 → 개발 → 음향 → 배포마다 담당 에이전트를 정합니다. Claude·Codex·피클·Muse·Grok Bot·OpenAI Dots처럼 같은 네트워크에 접속해 목록에 나타난 에이전트면 고를 수 있습니다. 담당자가 답장하면 그 내용이 다음 단계 요청에 인용되고, 보낼 요청 전문을 확인해 승인할 때만 전송됩니다. 답장이 도착했다고 다음 단계가 저절로 전송되지 않습니다.
- **배포는 한 번 더 승인**: 배포 단계는 화면의 승인 체크에 더해 OS 확인 창에서 승인해야 보냅니다.
- **개발 에이전트 실행**: Claude Code 또는 Codex를 고르고 프로젝트 폴더를 선택하면 OS 확인 창을 거쳐 `reason network serve`로 세션을 띄웁니다. 실행된 에이전트는 받은 요청에 따라 **그 폴더의 파일을 묻지 않고 수정**하므로 신뢰하는 프로젝트 폴더만 맡기세요. 홈 폴더, `~/.ssh` 같은 설정 폴더, 시스템 폴더는 선택할 수 없습니다. Studio를 종료하면 세션도 함께 종료됩니다. macOS·Linux에서만 동작합니다.
- **영상 요청 받기**: 외부 에이전트가 정해진 JSON 형식으로 보낸 영상 제작 요청과 스토리보드를 검토한 뒤 기존 영상 제작 작업으로 가져오고, 작업 상태를 요청자에게 답장할 수 있습니다.
- **모바일 연결(Android 리모컨)**: 설정 → 모바일 연결에서 원격 기능을 켜고 QR로 기기를 등록하면, 같은 사설 네트워크의 Android 앱에서 허용된 프로젝트의 팩토리 작업을 미리 보고 시작하고 진행 상태를 확인합니다. 기본값은 꺼짐이며 기기 권한 변경과 등록 해제는 Mac에서 합니다. 유료 API 등 승인이 필요한 결정은 Mac에서 합니다. Android 앱은 소스(`android/companion`)로 제공하며 이 릴리스에 APK는 포함하지 않습니다.
- 의존성 보안 권고 8건(hono, @hono/node-server, fast-xml-parser)을 해결했습니다.

알아 둘 점:

- 단계 요청의 "커밋·배포·외부 게시를 실행하지 말 것"은 상대 에이전트에게 보내는 요청문이며 Studio가 강제하는 장치가 아닙니다. 승인 전에 요청 전문과 인용된 답장을 확인하세요.
- 답장은 신뢰하지 않는 데이터로 다룹니다. 4 KiB까지 발췌해 인용문으로만 넣고, Studio가 그 안의 명령이나 경로를 실행하지 않습니다.
- Reason Network 엔진 0.12.17, Reason CLI 0.2.748의 규약에 맞췄습니다. 다른 엔진 버전에서는 연결하지 않고 안내합니다.
- Studio가 비정상 종료되면 실행해 둔 개발 에이전트 세션이 남을 수 있습니다. 터미널에서 해당 `reason network serve` 프로세스를 종료하세요.

확인 범위: Rust·TypeScript 단위 테스트와 계약 테스트(가짜 Reason 엔진, 가짜 `reason` CLI 사용), 뮤테이션 검사, IPC 고정 응답을 쓴 Chromium 화면 검사까지입니다. **실제 Reason 네트워크에서 외부 에이전트와 주고받은 단계 왕복, 실제 `reason network serve` 세션 실행, OS 확인 창 동작은 이 릴리스 시점에 확인하지 않았습니다.** 모바일 연결의 실제 Android 기기 등록과 작업 실행도 이 릴리스 노트에서 확인을 주장하지 않습니다. 벡터 색인(RAG)의 실시간 테스트 2건은 로컬 ChromaDB가 꺼져 있어 이번 검증에서 실행되지 않았습니다.

Mac은 Apple 공증이 적용되지 않았으며 Windows Authenticode는 미설정입니다. Tauri 업데이트 서명은 유지합니다. 자세한 사용법은 [Reason Network 연결](../REASON_NETWORK.md)을 참고하세요.
