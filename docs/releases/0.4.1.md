# Toris Studio 0.4.1

실제 앱을 직접 조작하며 찾은 문제와 화면 배치를 고쳤습니다. 데이터 구조와 권한은 바꾸지 않았습니다.

- **화면 배치**: 화면 제목 아래에 하위 탭을 두고, 좁은 창에서는 사이드바 아이콘 아래에 메뉴 이름을 표시합니다. 넓은 창에서는 콘텐츠 칸반의 네 열이 한 화면에 보입니다. 8~10px 글자는 11px 이상으로 키웠습니다.
- **SNS 관리**: 성과 카드가 필터보다 먼저 보입니다. 날짜 직접 선택과 이전 기간 비교는 접어 두었고, 분석 저장소 준비는 한 줄 안내로 바꿨습니다.
- **영상·모션**: 처리 환경·제작 단계·상태 확인을 한 줄로 합쳤고, 받은 초안이 없으면 수신함을 한 줄로 줄였습니다.
- **게시**: 안내 문장을 줄였고, 일괄 예약은 승인 영역 옆으로 옮겼으며 시작 시각 기본값을 다음 정각으로 넣습니다.
- **키워드 탐색**: 백그라운드 트렌드 수집 중에도 저장 자료 검색이 바로 동작합니다. 매 검색마다 뜨던 3,000자 안내를 없앴습니다.
- **작업함**: 이미지 요청을 누르면 작업 큐가 열리고, 요청 시각과 짧은 ID로 같은 이름의 요청을 구별합니다.
- **macOS 화면**: 창이 뒤에 있을 때 메뉴를 바꾸면 본문이 비던 문제, 화면 제목의 포커스 테두리, 메뉴 검색칸 이중 테두리, 얇게 보이던 드롭다운을 고쳤습니다. 화면을 옮기면 맨 위부터 보입니다.
- 콘텐츠 카드 미리보기에서 Markdown 기호를 숨깁니다. 원문은 그대로 유지합니다.
- 일정·작업에서 Google Calendar 미연결 안내가 두 번 뜨지 않습니다.
- 문구·모션 화면에 남아 있던 ChatGPT 전용 안내를 현재 동작(Agent 모델, Studio MCP로 연결한 외부 AI 도구)에 맞췄습니다.

확인 범위: 단위·계약 테스트, IPC 고정 응답을 쓴 Chromium 화면 검사, 뮤테이션 검사, 로컬에서 패키징한 macOS 앱을 실제 로컬 데이터로 띄워 화면을 조작한 확인. 실제 외부 계정 연결과 Windows 앱 화면은 출시 전 검사에 포함되지 않았습니다.

Mac은 Apple 공증이 적용되지 않았으며 Windows Authenticode는 미설정입니다. Tauri 업데이트 서명은 유지합니다.
