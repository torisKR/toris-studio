# SNS OAuth 연결

앱의 **SNS 로그인**에서 직접 등록한 플랫폼 앱으로 공식 로그인을 시작합니다. 계정 비밀번호를 Toris Studio에 입력하지 않습니다. Rust가 인증 코드와 토큰을 처리하고 OS 자격 증명 저장소에 저장합니다. React 화면에는 토큰·클라이언트 비밀키를 반환하지 않습니다.

## 플랫폼 앱 설정

다섯 제공자의 개발자 앱, 사용 권한, 테스트 사용자·앱 승인 조건을 먼저 준비하세요. Toris Studio는 클라이언트를 임의로 만들거나 승인된 상태로 표시하지 않습니다. 클라이언트 ID와 발급된 시크릿을 **앱 설정**에 입력합니다. 저장된 설정의 빈 입력은 기존 값을 유지합니다. 클라이언트나 리디렉션 주소를 변경하면 기존 계정 연결을 해제하고 다시 로그인해야 합니다.

클라이언트가 없으면 **로그인 설정 시작**을 눌러 필요한 설정과 안내를 확인합니다. YouTube 수집용 Data API KEY는 Google 계정 OAuth 클라이언트를 대신하지 않으며, 네이버 검색 API 설정만으로는 네이버 계정 로그인이 연결되지 않습니다. YouTube·네이버·TikTok 카드의 **공식 OAuth 설정 안내**는 시스템 브라우저에서 제공자의 공식 문서를 엽니다. 필수 입력 누락은 화면에 바로 표시하며, 설정 저장이 거절되면 수정할 수 있도록 입력한 값을 유지합니다. 저장 성공 또는 SNS 로그인 화면을 벗어나면 클라이언트 ID·시크릿 입력을 지웁니다.

| 플랫폼 | 현재 요청하는 권한 | 준비할 클라이언트 | 리디렉션 처리 |
| --- | --- | --- | --- |
| YouTube | `youtube.readonly` | Google 데스크톱 OAuth 클라이언트 | `http://127.0.0.1:38471/oauth/youtube/callback` |
| Threads | `threads_basic` | Meta Threads 앱·시크릿 | 등록된 HTTPS 주소로 이동 후 전체 URL 붙여넣기 |
| 네이버 블로그 | 네이버 계정 로그인 | 네이버 로그인 앱·시크릿 | `http://127.0.0.1:38471/oauth/naver_blog/callback` |
| TikTok | `user.info.basic` | Desktop Login Kit 클라이언트 키·시크릿 | `http://127.0.0.1:38471/oauth/tiktok/callback` |
| Instagram | `instagram_business_basic` | Meta 앱·시크릿, Business/Creator 계정 | 등록된 HTTPS 주소로 이동 후 전체 URL 붙여넣기 |

YouTube는 Google의 [설치형 앱 OAuth 안내](https://developers.google.com/youtube/v3/guides/auth/installed-apps)에 맞는 데스크톱 클라이언트를 사용합니다. 앱의 YouTube 공개 조회 기능은 별도의 Data API KEY를 사용합니다. OAuth 연결은 업로드·삭제·수익 조회 기능을 추가하지 않습니다.

TikTok은 [Desktop Login Kit](https://developers.tiktok.com/docs/en/login-kit-desktop)의 loopback 리디렉션과 PKCE를 사용합니다. 데스크톱 클라이언트 키를 UI의 클라이언트 ID 입력란에 넣습니다. 기본 권한은 계정 기본 정보이며 동영상 목록·업로드 권한은 요청하지 않습니다.

네이버는 [네이버 로그인 개발가이드](https://developers.naver.com/docs/login/devguide/devguide.md)에 따른 계정 토큰을 저장합니다. 현재 구현에 네이버 블로그 글쓰기·자동 발행 호출은 없습니다. 네이버 검색 API 클라이언트 설정과 로그인 연결을 구분하세요.

Threads·Instagram의 현재 구현은 Meta 앱에 등록한 HTTPS 콜백을 사용합니다. 앱 설정에는 소유한 등록 주소를 정확히 입력하고, 인증 후 브라우저가 이동한 `code`와 `state`가 포함된 전체 URL을 **로그인 후 이동한 전체 주소**에 붙여넣습니다. Instagram에는 소유 도메인의 `https://toris.kr/oauth/instagram/callback` 안내 페이지를 배포하고 Meta에 등록했습니다. 이 페이지는 인증 쿼리를 출력하거나 다른 서버로 전달하지 않습니다. 앱의 Rust가 전체 주소를 검증하고 토큰을 교환합니다. 다른 콜백 웹사이트가 쿼리를 지우거나 다른 주소로 이동하면 완료할 수 없습니다. 개인 Instagram 계정은 현재 연결 대상에 포함하지 않습니다.

## 로그인 완료와 저장

**브라우저에서 로그인**을 누르면 기본 시스템 브라우저에서 공식 제공자 페이지가 열립니다. **Aside로 로그인**은 설치된 Aside에서 엽니다. 운영체제의 기본 브라우저 설정은 변경하지 않습니다. Google·네이버·TikTok의 기본 로컬 콜백은 앱이 자동으로 받습니다. 동시에 하나의 로컬 콜백 로그인을 진행하고 포트 `38471`을 다른 서비스가 사용 중이면 해당 서비스를 확인하세요.

요청은 5분 뒤 만료됩니다. 완료하지 못했으면 **로그인 다시 시작**을 누릅니다. HTTPS 수동 콜백이나 자동 수신이 되지 않는 경우 브라우저의 최종 주소를 붙여넣어 완료할 수 있습니다. 입력란은 숨김 처리하며 완료·화면 이동 시 값을 지웁니다.

로컬 로그인을 다시 시작할 때 Rust는 이전 콜백 수신 작업을 취소하고 소켓이 닫힌 뒤 같은 포트를 다시 엽니다. 이전 요청의 `state`는 새 로그인에 사용할 수 없습니다. 다른 SNS에서 진행 중인 로컬 로그인은 먼저 완료하거나 **저장된 연결 해제**로 취소합니다.

Rust는 등록된 주소, 해당 제공자의 일회용 `state`, 허용된 코드 형식을 검증하고 잘못된 주소·중복 콜백·다른 제공자의 상태 값을 거절합니다. 인증 URL과 토큰 응답의 리디렉션도 제한합니다. 성공한 토큰 응답을 OS 저장소에 기록한 뒤에만 계정 연결 상태가 바뀝니다.

## 갱신과 다시 로그인

앱 실행 중 만료가 가까운 연결을 주기적으로 확인하고 공식 갱신 프로토콜을 호출합니다. 앱을 종료한 동안에는 갱신하지 않습니다. 다시 실행하면 저장된 연결을 읽고 갱신 가능한 토큰을 확인합니다. Google·네이버·TikTok은 유효한 갱신 토큰이 있으면 만료된 액세스 토큰을 갱신할 수 있습니다. 제공자마다 발급 조건·만료 정책이 달라 성공을 영구적으로 보장하지 않습니다.

Threads·Instagram은 유효한 장기 액세스 토큰을 갱신하며 발급·이전 갱신 후 24시간이 지나야 합니다. 이미 만료된 장기 토큰은 다시 로그인해야 합니다. 플랫폼 권한 철회·무효화 응답은 **다시 로그인 필요**로 표시합니다. 일시적인 네트워크 오류는 제한된 간격으로 다시 시도합니다. 앱의 **연결 갱신**으로 수동 갱신 결과를 확인할 수 있습니다.

화면의 만료 일시는 한국 시간으로 표시합니다. 연결 상태·만료 표시만으로 실제 API 조회나 게시가 성공했다고 판단하지 않습니다. 실제 사용자 앱의 로그인 성공·OS 저장소 재읽기·토큰 갱신은 등록된 클라이언트와 해당 계정으로 따로 검증해야 합니다.

## 브라우저 쿠키와 연결 해제

브라우저 로그인 쿠키는 시스템 브라우저가 관리합니다. Toris Studio는 쿠키를 추출·복제하거나 만료 일시를 연장하지 않습니다. 앱이 저장하는 세션은 OAuth 액세스·갱신 토큰과 만료 정보입니다. macOS는 Keychain, Windows는 Credential Manager를 사용하며 비밀 정보를 공개 저장소에 넣지 않습니다.

**저장된 연결 해제**는 Toris Studio에 저장된 계정 토큰과 진행 중인 요청을 삭제합니다. 등록한 앱 설정과 브라우저 로그인은 유지합니다. SNS에서 앱 권한까지 철회하려면 해당 플랫폼의 연결된 앱 관리에서 해제하고, 브라우저 로그아웃은 브라우저에서 진행합니다.

OpenAI·Claude 구독 계정은 SNS OAuth와 별개입니다. 해당 계정 로그인은 OpenCodex·teamclaude 또는 로그인한 Claude CLI에서 처리하며 Toris Studio는 그 로컬 인터페이스를 사용합니다. [데스크톱 설치·연결](DESKTOP.md)을 참고하세요.

## macOS 키체인 승인

macOS의 연결 설정과 OAuth 기록은 Toris Studio 전용 통합 키체인 항목으로 옮깁니다. 기존 값을 읽는 첫 이전 과정에서는 macOS의 승인이 필요할 수 있습니다. 승인해 읽은 값이 통합 항목에 저장된 뒤에는 같은 설치본을 재실행할 때 기존 항목을 다시 읽지 않습니다. 앱 실행 중 읽은 값도 메모리에서 재사용합니다. 평문 설정 파일로 비밀 값을 옮기거나 모든 앱에 접근 권한을 부여하지 않습니다. Windows는 기존 자격 증명 저장 방식을 유지합니다.

사용자가 거절하거나 저장소 오류가 나면 상태 확인이 같은 승인 창을 계속 열지 않습니다. **저장소 권한 다시 확인**을 직접 눌러 재시도할 수 있습니다. 실패한 재시도는 실행 중 설정을 교체하지 않습니다. 기존 항목은 이전 시 보존하며, 명시적인 연결 해제는 해당 연결의 이전 기록도 삭제합니다.

현재 macOS 빌드는 로컬 ad-hoc 서명입니다. 같은 설치본에 대한 승인과 새 빌드로 교체할 때의 승인은 다릅니다. ad-hoc 서명은 실행 파일 해시로 앱을 식별하므로 업데이트 후 macOS가 다시 승인을 요구할 수 있습니다. 후속 업데이트까지 동일한 앱으로 신뢰받으려면 동일한 지속 코드 서명 인증서를 사용해야 합니다. [Apple 코드 서명 요구사항](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)
