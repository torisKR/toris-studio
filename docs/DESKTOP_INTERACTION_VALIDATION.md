# 데스크톱 인터랙션 및 리소스 관리 검증

검증일: 2026-10-11. 현재 로컬 소스에 적용한 변경과 실제 수행한 검증을 기록합니다. 설치된 앱 교체, 업데이트 설치, 실제 SNS 게시 및 공개 Worker 배포는 실행하지 않았습니다.

## 사용 방법과 변경 사항

- 상단 **메뉴 검색** 또는 **⌘ K / Ctrl K**로 화면을 검색합니다. 방향키로 선택하고 Enter로 이동하며 Esc로 닫습니다. 이미 열린 입력·확인 창이 있으면 검색 창을 겹쳐 열지 않습니다.
- 저장·수집·ChatGPT 요청 등 실제 작업 상태를 상단에 표시합니다. 실행 중인 작업은 Tauri의 네이티브 진행 표시에도 반영합니다. Windows에서는 작업 표시줄, macOS에서는 Dock 진행 표시와 작업 배지를 사용합니다. 전체 크기를 아는 업데이트 다운로드에만 백분율을 표시합니다.
- **영상 제작 → MP4 출력 완료 → 새 창에서 미리보기**는 Tauri `WebviewWindowBuilder`로 재생 전용 창을 엽니다. 이미 열린 창은 재사용하고 새로 선택한 영상을 표시합니다. 기본 화면의 백그라운드 작업을 미리보기 창에 다시 마운트하지 않습니다.
- 업데이트는 Rust에서 `tauri-plugin-updater`를 통해 확인·다운로드·서명 검증·설치·재시작합니다. 화면은 단계와 취소·오류·재시도를 표시합니다. 상태 revision을 비교해 늦게 도착한 조회나 이벤트가 최신 진행 상황을 덮어쓰지 않도록 했습니다. 업데이트 진행 표시가 일반 작업보다 우선하며, 업데이트가 끝나면 일반 작업 표시를 복원합니다.

## 리소스 정리와 권한

- 변경한 조회·미리보기·에셋 상세 경로에서 화면 해제와 재활성화에 맞춰 이벤트 구독, 타이머, RAF, observer를 정리합니다. 숨겨진 패널의 반복 조회와 상태 시계가 불필요하게 계속 돌지 않도록 처리했습니다. 해당 경로의 화면이나 선택 대상이 바뀌면 늦은 읽기 결과를 화면에 반영하지 않습니다.
- 초기 대시보드 중복 조회를 합치고 저장 직후 기존 조회를 무효화합니다. 오래된 읽기 결과가 새로 저장한 콘텐츠·채널을 덮어쓰는 경합도 방지합니다.
- 3D 미리보기는 geometry, material, texture, skeleton, ImageBitmap 및 WebGL context를 정리합니다. 초기화 도중 오류가 나거나 로딩 완료가 늦게 도착한 경우에도 정리 경로를 적용합니다.
- 영상 변경·창 해제 시 플레이어를 정지하고 `src`를 제거합니다. Rust의 이전 파일 핸들도 해제합니다. 창 생성은 중복 요청을 누적하지 않으며, 늦게 도착한 이전 창의 종료 이벤트가 새 창의 파일을 지우지 않도록 세대를 확인합니다.
- 미리보기 창에는 IPC 권한을 부여하지 않습니다. 기본 로컬 `main` 창만 92개 등록 명령과 제한된 이벤트 권한을 사용합니다. 새 명령 두 개는 작업 상태와 렌더 미리보기 전용입니다. 원격 페이지에 권한을 추가하지 않았습니다.
- `toris-preview` 프로토콜은 해당 미리보기 WebView와 현재 선택한 MP4만 제공합니다. 허용된 렌더 폴더의 UUID 파일, 일반 파일 여부와 크기를 검사하고 파일 핸들을 고정합니다. 임의 경로·이전 토큰·잘못된 범위 요청을 거부하며, 읽기는 최대 1 MiB씩 네 개로 제한합니다. 로컬 HTTP 서버나 전체 파일 시스템 공개 권한은 사용하지 않습니다.

추가로 격리된 Chromium UI 검증을 실행했습니다. 실제 계정·키체인·게시 API를 호출하지 않습니다.

- `node scripts/verify-desktop-interactions.mjs`: 메뉴·화면 이동 20회, 초기 StrictMode 조회 한 번, 키보드 리스너 1→1, 타이머 1→1. 타이머 한 개는 개발 서버의 heartbeat를 포함한 기준값입니다. 820px에서 가로 넘침과 런타임 오류가 없었습니다.
- `node scripts/verify-native-preview.mjs`: 영상 선택 교체 20회, IPC 호출 0, 기본 App 모듈 로드 0. 미리보기 리스너 1→1, unload 리스너 2→2이며 unload 기준에는 Vite 리스너도 포함됩니다. 교체마다 이전 영상 해제와 새 소스 로드가 실행됐습니다. 480px에서 가로 넘침과 런타임 오류가 없었습니다. 미디어는 비활성 테스트 데이터이며 실제 MP4 디코딩 검증은 아닙니다.
- UI 리포트와 스크린샷은 `/private/tmp/toris-desktop-interactions/` 및 `/private/tmp/toris-native-preview/`에 저장했습니다. 임시 테스트 서버와 브라우저는 종료했습니다.
- 기존 macOS·Windows CI에 네이티브 창과 updater 테스트를 추가했습니다. 이번 변경의 원격 CI 실행 결과는 아직 없습니다.

## 남은 실기 검증

컴파일·계약·격리 UI 검증은 리스너와 핸들 등의 반복 누적 방지 근거입니다. 모든 상황에서 메모리 누수가 없다는 증명은 아닙니다. 설치된 macOS·Windows 앱에서 창 열기·재사용·닫기, Dock·작업 표시줄, WebKit·WebView2의 실제 MP4 재생, 장시간 GPU·프로세스 메모리 측정 및 실제 업데이트 설치는 별도로 확인해야 합니다.

선택된 OAuth Worker 프록시 취약점 수정은 로컬 소스와 회귀 테스트에 반영되어 있습니다. 공개 배포 반영 여부는 이번 작업에서 확인하지 않았습니다.
