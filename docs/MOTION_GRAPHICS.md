# 모션 그래픽 제작

영상 제작 → 모션 그래픽에서 한국어, 세로 9:16, 5장면, 45초로 시작합니다. 타이틀·수치 강조·차트·비교·단계 설명 구성을 선택할 수 있습니다. 모든 기본 수치는 예시이며 자료 입력에서 확인·교체하세요. 가로 16:9로 전환하면 요소 좌표도 비율에 맞춰 바뀝니다.

설명문과 CSV/탭 구분 표를 붙여넣고 확인 가능한 표 편집기로 수정합니다. 표는 항목·숫자 두 열이며 1~24행, 0 이상 숫자를 지원합니다. 차트는 표 ID를 참조합니다. PNG/JPEG/WebP는 요소 추가 → 이미지에서 가져옵니다. 원본은 로컬에 보관하며 ChatGPT에는 ID·크기·설명만 전달합니다. 이미지를 실제 대화에 첨부할 필요가 있으면 기존 에셋 파일 수신 경로를 사용합니다.

장면은 12개, 전체 길이는 180초, 장면당 요소는 32개까지입니다. 텍스트·사각형·원·선·이미지·막대/선/도넛 차트를 추가하고 캔버스에서 이동·크기 조절하거나 속성의 숫자 입력을 사용하세요. 방향키는 1px, Shift+방향키는 10px 이동입니다. 장면 순서·길이 조절, 요소/장면 복제·삭제와 실행 취소·다시 실행을 지원합니다.

## ChatGPT 연결

기본 전달 연결은 Remote Desktop Commander입니다. 요청을 만들면 현재 실행 중인 앱의 `--studio-mcp` 표준입출력 연결을 사용하는 전달문이 표시됩니다. 전달문을 ChatGPT에 붙여넣고 Remote Desktop Commander로 계속하면 앱이 보관한 요청을 읽고 변경 초안만 반환합니다. 별도 모델 API 키나 Codexify 설정이 필요하지 않습니다. 설치된 이전 앱과 검증용 앱을 구분하도록 현재 앱의 실행 파일 경로를 사용합니다.

기존 Codexify 연결도 선택할 수 있습니다. 이 경우 코딩 화면의 연결에 새 모션 도구가 있어야 합니다.

- `studio_motion_request_get(requestId)`는 요청 당시 프로젝트·선택 ID·지시·자료와 편집 해시를 읽습니다.
- `studio_motion_draft_receive(requestId, projectId, baseHash, draft)`는 검증한 변경 초안만 보관합니다. 프로젝트 저장·적용·출력을 실행하지 않습니다.

요청 방식(새 구성/기존 수정)과 범위(전체/장면/요소)를 지정하세요. Remote Desktop Commander 전달문은 ChatGPT 대화에 직접 붙여넣고 계속해야 합니다. Codexify 대화가 실행 중이 아니면 “대화 재개 필요”가 표시됩니다. 요청 저장·전달은 생성 완료를 뜻하지 않습니다.

수신된 변경은 전후 장면과 전체 변경 데이터를 검토한 뒤 적용하거나 거절합니다. 검토 장면 선택으로 추가·삭제한 장면도 확인할 수 있습니다. 적용은 실행 취소 한 단위이며 별도로 프로젝트를 저장해야 합니다. 수동 편집이 발생한 결과는 충돌로 거부합니다. 동일 결과의 재수신은 멱등 처리하고 취소·다른 프로젝트·24시간 지난 요청을 거부합니다. 완료·취소 요청은 활성 목록이 차면 로컬 보관함으로 옮겨 원본을 유지합니다.

수치 수정은 기본적으로 허용되지 않습니다. “Q3를 18로 변경”처럼 원본 수치를 바꾸려면 전체 범위에서 **원본 수치 변경 초안 허용**을 선택하세요. `set-table-value`는 tableId·행 번호·항목·기존 수치·새 수치를 모두 지정해야 하며, 검토 화면에 전후 값이 표시됩니다. 다른 요소와 표 행은 유지됩니다.

## 출력과 저장

정지 미리보기와 영상은 같은 Rust CPU 합성기를 사용합니다. 저해상도 재생과 1080p 출력은 프로젝트 해시·해상도로 캐시하고 이전 편집 내용의 결과는 화면에서 폐기합니다. 출력은 1080×1920 또는 1920×1080, 24fps, H.264/AAC MP4입니다. 기존 음성 경로는 유지하며 새 음성을 생성했다고 표시하지 않습니다.

프로젝트 저장은 기존 로컬 프로젝트 저장소를 사용합니다. 편집 복구본은 로컬 WebView 저장소에 보관합니다. 기존 텍스트·프리셋 프로젝트는 변환하지 않습니다. MP4 출력 완료 후 MP4 저장에서 위치를 선택하세요. 번들 도구 누락·손상은 공식 설치 파일로 복구해야 합니다.

FFmpeg/FFprobe 9.0.2와 libx264·zlib, Noto Sans CJK KR의 해시·라이선스·대응 소스·빌드 지침은 앱의 `media-runtime/`에 동봉합니다. 설치 검사 `--motion-smoke`는 사용자 설정을 읽지 않고 합성 자료로 정지 프레임·세로 MP4·가로 재생 영상을 생성합니다.
