# Toris Studio Android 리모컨

Mac의 Toris Studio가 켜져 있고 같은 사설 네트워크에 있을 때 사용한다. 기본적으로 Mac 원격 기능은 꺼져 있다. Android에는 모델, Mac 자격 증명, 프로젝트 파일을 저장하지 않는다.

## 화면과 기능 설계

[Orca 모바일 작업 공간](https://www.onorca.dev/docs/mobile)의 연결된 호스트와 작업 목록, 상태 중심 탐색을 참고해 Toris Studio의 어두운 색상과 한국어 콘텐츠로 구성한다.

- **작업**: Mac 연결 상태, 불러온 작업 수와 승인 대기 수, 상태 필터, 이 기기에서 시작한 작업 카드와 이전 작업 더 보기를 제공한다. 목록 수치는 현재 불러온 범위의 개수다.
- **작업 상세**: 동일한 작업 ID와 현재 단계, Mac 승인 사유, 단계별 결과, 필수·선택 검증, 템플릿 여부, 기록된 비용을 표시한다. 진행 중인 본인 작업은 확인 후 취소할 수 있다.
- **새 작업**: Mac이 허용한 프로젝트, 요청, 종류·화면·방향을 선택한다. 규칙 기반 미리보기와 작업 시작을 구분하고, 응답을 받지 못한 요청은 기존 요청 ID로 복구하거나 같은 입력으로 재전송한다.
- **연결**: 연결 상태, 호스트 지문, QR 스캔, 기기 지문과 확인 코드, 카메라 권한 재시도 및 라이선스를 제공한다. 기기 권한 변경과 등록 해제는 Mac에서 한다.

Mac은 목록과 상세를 요청할 때마다 기기 소유권과 현재 프로젝트 권한을 검사한다. 목록은 한 번에 12개씩 가져오며, 표시 제목은 길이·문자·비밀값 패턴을 검사한다. 제목이 안전하지 않으면 종류와 프로젝트 이름을 표시한다. 원시 로그·경로·임의 명령·승인 수단은 전달하지 않는다. 휴대폰이 연결을 종료한 뒤에도 Mac은 해당 작업의 안전한 상태 요약을 로컬에 갱신한다. Mac 런타임에서 이전 작업을 찾을 수 없으면 마지막으로 저장한 안전한 요약을 **마지막 저장 상태**로 표시한다. 요약도 없는 경우 상태가 없다고 표시한다. 휴대폰이 오프라인이면 새 결과를 받은 것처럼 표시하지 않는다.

앱은 화면에 보이는 동안만 연결한다. 백그라운드 SSH, 외부 릴레이, 푸시 알림, 휴대폰에서의 범용 승인·셸·파일 편집은 제공하지 않는다. 대기·오류·권한 거절·빈 목록·오래된 결과를 각각 구분하고, 상태를 색상과 텍스트로 함께 표시한다.

## 실행과 연결

1. 저장소 루트에서 `pnpm desktop:dev`로 Mac 앱을 실행하고 **설정 → 모바일 연결**에서 사설 네트워크 인터페이스를 선택해 원격 기능을 켠다.
2. Android 빌드: `cd android/companion && ./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`. APK는 `app/build/outputs/apk/debug/app-debug.apk`다. `adb install -r app/build/outputs/apk/debug/app-debug.apk`로 디버그 기기에 설치할 수 있다.
3. Mac에서 기기 추가를 눌러 QR을 발급하고, 앱에서 카메라 권한을 허용한 뒤 스캔한다. 두 화면의 **기기 지문과 확인 코드**를 비교하고, Mac에서 허용할 프로젝트를 선택해 승인한다. QR은 2분 내 만료되며 재발급 시 이전 QR은 사용할 수 없다.
4. 승인을 받으면 앱은 새로운 SSH 공개키 인증으로 접속한다. 허용된 프로젝트를 선택하고 작업을 미리 보거나 시작한다. 작업 ID는 Mac과 휴대폰에서 같다. 실행 중 연결이 끊겨도 Mac에서 작업을 이어가며, 다시 접속한 앱은 저장된 요청 ID로 상태를 복구한다.
5. Mac의 모바일 연결에서 기기를 등록 해제하면 활성 연결이 닫히고 해당 키는 재인증할 수 없다. 휴대폰 앱 재설치 또는 키 분실 시 다시 등록한다. Mac의 호스트 키나 사설 IP가 바뀌면 기존 기기를 등록 해제한 뒤 새 QR로 다시 등록한다. 동일한 IP에서는 Mac 앱을 다시 켜도 기존 전용 포트를 사용한다.

같은 요청을 재전송하면 기존 작업을 복구한다. 이전 요청의 결과를 확인하지 않고 새 요청을 만들면 별도 작업이 생길 수 있으므로 Mac에서 먼저 확인한다. 유료 API 등 기존 승인이 필요한 작업은 Mac에서 결정한다.

## 사용한 SSH 및 QR 라이브러리

- SSH: [mwiede/jsch](https://github.com/mwiede/jsch/blob/master/LICENSE.txt) 2.28.4. BSD 계열 라이선스로 상업적 이용과 바이너리 재배포가 가능하며 저작권·조건·면책 고지가 필요하다. 동봉한 jbcrypt 및 jzlib 고지도 함께 유지한다. 전체 고지문은 앱의 **오픈소스 및 QR 라이선스** 화면과 `app/src/main/assets/licenses/`에 있다.
- QR: [Google ML Kit Barcode Scanning](https://developers.google.com/ml-kit/vision/barcode-scanning/android) 17.3.0의 앱 내장 모델. [ML Kit 및 Google API 이용약관](https://developers.google.com/ml-kit/terms)이 적용되므로 배포 전 최신 약관을 확인한다. 약관에 따르면 입력 이미지와 결과는 기기에서 처리되지만 SDK의 성능·사용 통계가 Google로 전송될 수 있어 앱에서 이를 안내한다. ML Kit의 동봉 제3자 고지문도 앱에서 구성요소별로 확인할 수 있다.

QR 원문, 일회용 등록값과 SSH 개인키는 앱 자체 로그나 분석에 기록하지 않는다. 이 설명은 라이브러리의 향후 약관 변경을 대체하지 않는다.
